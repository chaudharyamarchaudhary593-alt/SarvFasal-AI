# 🌾 SarvFasal AI

A smart farming website prototype that helps farmers ask questions, check crop health and calculate profit. Built with plain HTML, CSS and JavaScript.

> **Status:** Early prototype. The AI assistant and leaf check currently give demo responses only. Real AI, live weather and mandi data are planned.

## Features

- **AI Assistant:** chat box that answers basic farming questions (water, fertilizer, pests, weather, mandi). Currently keyword-based demo answers.
- **Leaf Photo Check:** upload a photo of a leaf and preview it. Disease detection is not connected yet.
- **Language Toggle:** switch the whole site between English and Hindi.
- **Profit Calculator:** enter land area, yield, price and cost to see income and profit or loss.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any browser (double-click it, or run `open index.html` on Mac).

No installation or build step is needed.

```bash
git clone https://github.com/YOUR-USERNAME/sarvfasal-ai.git
cd sarvfasal-ai
open index.html
```
